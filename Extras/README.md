# Extras

Small standalone physics and maths programs, each in its own folder.

| Folder | What it is |
|---|---|
| [double-pendulum-sim](double-pendulum-sim) | Animated chaotic double pendulum with live angle plots |
| [compute-pi](compute-pi) | Pi to N decimals via the Chudnovsky algorithm |
| [compute-euler](compute-euler) | Euler's number e to N decimals via the series 1/n! |
